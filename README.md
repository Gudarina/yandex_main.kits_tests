# Тесты на проверку параметра name в запросе на создание набора в Яндекс.Прилавок с помощью API Яндекс.Прилавок.
CОСТАВ ПРОЕКТА
configuration.py - адрес тестового стенда и пути к запросам 
data.py - данные для создания пользователя и набора
sender_stand_request.py - функции отправки POST-запросов, создания пользователя и получения токена авторизации
create_kit_name_kit_test.py - автотесты для проверки поля name
README.md - описание проекта и инструкция по запуску
.gitignore - список файлов, которые не нужно добавлять в Git

ПОДГОТОВКА К ЗАПУСКУ СТЕНДА
Указать адрес тестового стенда в файле configuration.py
Проверить данные для создания пользователя в файле data.py
Установить необходимые библиотеки

ЗАПУСК АВТОТЕСТОВ
Открыть терминал в папке проекта и выполнить команду: pytest create_kit_name_kit_test.py
Для подробного отображения результатов выполнить:pytest -v create_kit_name_kit_test.py

ОЖИДАЕМЫЙ РЕЗУЛЬТАТ
Позитивные проверки: код ответа 201, значение name в ответе совпадает со значением в запросе
Негативные проверки: код ответа 400
